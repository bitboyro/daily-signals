# Changelog

All notable Daily Signals changes are recorded here. The repository history remains the authoritative, replayable implementation record.

## 1.0.0 — 2026-11-16

- Added licensed RSS/Atom ingestion, candidate normalization, review and deduplication.
- Added the producer workspace for review, scripts, pronunciations, audio preview, approval audit and publication.
- Added dated editions, archive, podcast feed and an accessible Romanian/English PWA listener.
- Added fixture and optional pinned local Kokoro speech, WAV validation and generated-audio provenance.
- Added checksum-bound publication through an S3-compatible object store and Rust byte-range streaming.
- Added PostgreSQL persistence, OIDC/role authorization and idempotent v0.x data/recording migration.
- Added one-command Compose installation, checksummed backup/restore, health and Prometheus endpoints, structured logs and operator guides.
- Added multi-runtime, container, security, migration, browser, accessibility, performance, nightly and release qualification.
- Added Decision Lab shadow planning with public annotations and explicit human overrides.

See the [v1.0.0 release notes](docs/releases/v1.0.0.md) for installation, compatibility and evidence details.
